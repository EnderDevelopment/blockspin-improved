# BlockSpin Improved

BlockSpin Improved is a Roblox script that enhances the classic BlockSpin game with improved features and customization options. This script includes client-side and server-side components, a user interface, and a configuration file to adjust game settings. Keywords: Roblox, BlockSpin, game, script, customization, multiplayer.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio project.
3. Place the `BlockSpinScript.lua` file in the `ServerScriptService` folder.
4. Place the `BlockSpinClient.lua` file in the `StarterPlayerScripts` folder.
5. Place the `BlockSpinUI.lua` file in the `StarterGui` folder.
6. Place the `BlockSpinConfig.lua` file in the `ServerScriptService` folder.

## Use

1. Customize the game settings in the `BlockSpinConfig.lua` file.
2. Run the game in Roblox Studio.
3. Players can interact with the game using the provided UI and controls.
